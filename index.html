សូមស្វាគមន៍មកកាន់ វេបសាយគណិតវិទ្យា(កឌាន ភក្តី)

Let $\mathbb{C}$ be a complex linear space over $\mathbb{C}$ with norm $||\cdot|| : \mathbb{C} \to \mathbb{R}$ such that $||z|| = |z| = \sqrt{a^2+b^2}, \forall z = a+bi$. Show that $(\mathbb{C}, ||\cdot||)$ is a normed space.

Solution

We show that:

(1) $||z|| = |z| = \sqrt{a^2 + b^2} \ge 0 \quad \forall z = a + ib \in \mathbb{C}$; hence $||z|| \ge 0$.

(2) Let $z = a + ib \in \mathbb{C}$
$||z|| = |z| = \sqrt{a^2 + b^2} = 0 \iff a = b = 0 \iff z = 0 + 0i = 0$.

(3) Let $z, w \in \mathbb{C}$

$$ \begin{aligned} ||z + w||^2 &= (z+w)(\overline{z+w}) \quad \text{where } \overline{z+w} = \text{conjugate of } z+w \\ &= (z+w)(\bar{z} + \bar{w}) = z\bar{z} + w\bar{w} + w\bar{z} + \bar{w}z \\ &= z\bar{z} + w\bar{w} + w\bar{z} + \overline{w\bar{z}} \\ &= z\bar{z} + w\bar{w} + 2\text{Re}(w\bar{z}) \\ &\le ||z||^2 + ||w||^2 + 2||w|| \cdot ||z|| = (||z|| + ||w||)^2. \end{aligned} $$

Thus, $||z + w||^2 \le (||z|| + ||w||)^2$ and hence, $||z + w|| \le ||z|| + ||w||$.

(4) Let $z \in \mathbb{C}, \alpha \in \mathbb{C}$,
$||\alpha z|| = |\alpha z| = |\alpha(a+ib)|$

$$ = \sqrt{(\alpha a)^2 + (\alpha b)^2} = \sqrt{\alpha^2(a^2 + b^2)} = \sqrt{\alpha^2}\sqrt{a^2 + b^2} = |\alpha| \cdot ||z||. $$
